# 🗓️ ContentForge — 30-Day Social Media Calendar Generator

A zero-dependency, single-file tool that generates a branded **30-day social content calendar** in seconds: post ideas, captions, hashtags, platform mixes, and best posting times — exportable as a clean PDF. Built for small businesses that know they should post but never know *what*.

## Why this sells

- **Agencies charge $500+/month** for content calendars; this costs the buyer once.
- **Niche variants from one codebase**: each niche (restaurant, gym, real estate, dentist, salon, retail, generic) has its own content pillars, idea bank, hashtags, and posting strategy — sell them as separate listings.
- **Regenerates forever**: every click produces a fresh month of ideas, so buyers never "finish" the product.
- **Zero infrastructure**: one `index.html`, free hosting, nothing to maintain.

## Features

- **7 niche packs** — content pillars, curated idea banks, niche hashtags, and strategy tips per niche
- **30-day calendar** auto-sized to the selected month (28–31 days), rotating through pillars
- **Platform toggles** (Instagram, Facebook, TikTok, LinkedIn) with per-platform best posting times
- **Brand-aware hashtags** — your brand name becomes a hashtag automatically
- **Copy as text** for planning tools, or **print-optimized PDF export** (no watermark)
- Everything client-side; works offline

## Run it

Open `index.html` in any modern browser. Host free via [Netlify Drop](https://app.netlify.com/drop) or GitHub Pages.
