# 📄 ProposalForge — Proposals, Quotes & Contracts for Freelancers

A zero-dependency, single-file web app that generates professional **proposals, quotes, and contracts** — the pre-sale paperwork that comes *before* the invoice. Part of the **Freelance Paperwork Suite** with [InvoiceForge](../).

## Why this sells

- **Bundle economics**: buyers of InvoiceForge are exactly the people who need this. Cross-sell as *"The Complete Freelance Paperwork Suite — $35"* and raise your average order value.
- **Three products in one file**: Proposal, Quote, and Contract modes each with their own clause library.
- **Typed signatures**: both parties sign by typing their name — a legally recognized e-signature in most jurisdictions (ESIGN/eIDAS).
- **Zero infrastructure**: one `index.html`. No backend, no accounts, no subscription.

## Features

- **3 document modes**: Proposal / Quote / Contract with tailored intros and templates
- **Clause library**: pre-written, freelancer-friendly terms (scope, revisions, IP ownership, confidentiality, termination, liability…) — click to add, or write custom clauses
- **Scope of work table** with qty × rate pricing, tax support, 6 currencies
- **Typed e-signatures** for both parties with signature lines and dates
- **Live side-by-side preview** with clean, print-optimized PDF export (no watermark)
- **Save/load drafts** in the browser — all data stays on the customer's device

## Run it

Open `index.html` in any modern browser. To host it free, drop the folder on [Netlify Drop](https://app.netlify.com/drop) or use GitHub Pages.
