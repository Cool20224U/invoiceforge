# 🧾 LegalForge — NDA, IP Assignment & Service Agreements for Freelancers

A zero-dependency, single-file generator for the legal paperwork freelancers need to **protect their work**: NDAs, IP assignments, and service agreements. Completes the Freelance Business-in-a-Box trilogy with [InvoiceForge](../) and [ProposalForge](../proposalforge/).

**The funnel:** win the client (ProposalForge) → protect the work (LegalForge) → get paid (InvoiceForge).

## Why this sells

- **Fear-driven purchase**: freelancers worry about clients stealing work, ideas, or IP. This is the cheapest "insurance" they'll ever buy.
- **Three documents in one file**: Mutual NDA, IP Assignment, Service Agreement — each with a curated clause set.
- **Typed e-signatures** (legally recognized in most jurisdictions under ESIGN/eIDAS).
- **Zero infrastructure**: one `index.html`, no backend, no subscription.

## Features

- 3 document modes with professionally worded, plain-English clauses
- Click-to-add/remove clause library per document type
- Party details, fee/currency fields, dates auto-merged into every clause
- Typed e-signature blocks for both parties
- Live preview + clean, print-optimized PDF export
- Save/load drafts via localStorage — data never leaves the device

## Run it

Open `index.html` in any modern browser. Host free via [Netlify Drop](https://app.netlify.com/drop) or GitHub Pages.
